# Shieo Shakti Chemical Earthing

A responsive React and TypeScript homepage for Shieo Shakti's chemical earthing and lightning protection services.

## Development

Install dependencies with `npm install`, then start the local Vite server with `npm run dev`.

## Production build

Run `npm run build` to type-check and create the production build in `dist/`. Use `npm run preview` to preview that build locally.

## Homepage sections

- Hero and click-to-call contact actions
- Earthing safety overview and benefits
- Service highlights
- Patna business contact details
